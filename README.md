|---|---|

| **Impact** | Autonomous task execution, AI-powered web research exported to Markdown, safe codebase modification via approval workflow |

**What it does:** Runs in Agent Mode (autonomous multi-step task execution), Plan Mode (structured implementation plans/architectures), or Ask Mode (web research saved as Markdown) — accessible from the terminal or Telegram. Every code change is staged with a diff viewer before being applied.

**My contribution:** Designed the full agent architecture — the three-mode system, Firecrawl-based search/scraping integration, the staged file-editing approval workflow, and both the CLI and Telegram interfaces.
