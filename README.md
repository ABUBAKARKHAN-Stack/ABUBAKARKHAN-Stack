<details open>
<summary><b>🛒 ShopNex — Enterprise-Grade Microservices E-Commerce Platform</b></summary>
<br/>

A full MERN (100% TypeScript) e-commerce engine built across **3 focused months**, designed around real production-grade backend complexity rather than a typical CRUD app.

| | |
|---|---|
| **Stack** | React, Node.js, Express, MongoDB/Mongoose, Kafka, Redis, Stripe, TanStack Query, Tailwind, shadcn |
| **Scale** | 5 microservices + 1 API gateway · centralized session auth · ~9,000 lines refactored |
| **Impact** | Full checkout & order lifecycle, Stripe + COD payments, real-time admin dashboards, role-based access |

**What it does:** Complete e-commerce system with user-side cart/wishlist/checkout/order-tracking and an admin side for product, order, and shipping management — built on an event-driven microservices architecture.

**My contribution:** Designed and built the entire system solo — architected the 5-service + gateway microservices layout, implemented Kafka-based inter-service communication, centralized JWT/session auth at the gateway, integrated Stripe with webhook handling, and built the full frontend with React Hook Form, Zod, Framer Motion, and an atomic-design component structure.

</details>

| | |

| **Impact** | Fully customizable agency CMS — content, services, and portfolio items managed without code changes |
